# AW3 RTS 原版执行权收归设计

## 目标与边界

AW3 继续负责战争战略，WorldBox 原版负责 Actor、Army、Taxi 和 City 的实际状态迁移。任何可变状态只能有一个执行所有者。

本设计不删除战争导演、军团任务、阵型意图、补员、战争目标、运输优先级或异步战略评分。

## 1. 分层所有权

### AW3 战略层

AW3 唯一负责：

- 战争目标和城市进攻顺序。
- 军团在集结、进攻、防守、追击、撤退和运输任务间的分配。
- 陆路与海路成本比较、战略途经点和运输需求。
- 阵型意图、集结完成条件、补员要求和卡死恢复策略。

### 原版执行层

原版唯一负责：

- Actor 的 `goTo`、路径验证、逐步移动和地块副作用。
- Army 创建、成员变更、统帅变更、销毁、dirty 标记和存档。
- TaxiRequest 合并、船只分配、登船、装载、航行、登陆、取消和完成。
- City 占领进度自然完成、`finishCapture` 和 `joinAnotherKingdom`。

## 2. 移动执行

`AWPathFinder` 和异步规划保留为只读战略路线建议器。它可以返回路线成本、推荐陆海方式和有限数量的途经点，但不得直接修改 Actor 的 `current_tile`、`current_path` 或 batch 状态。

统帅对每个战略路线段调用原版 `Actor.goTo`。士兵使用原版 follower 任务靠近统帅；AW3 只设置目标和观察进度。小范围阵型修正可以调用原版 `moveTo`，但必须遵守原版地块副作用。

卡死恢复顺序：等待原版路径、重新提交当前段、重新规划战略段、回到统帅或安全城市；只有普通士兵长期无法接近统帅时才使用现有传送兜底。统帅和运输中的 Actor 不得直接传送跨海。

## 3. Army 生命周期

所有普通军团和特殊军团通过原版 `ArmyManager.newArmy` 创建，通过 `Army.setCaptain` 和 Actor 的 `setArmy/removeFromArmy` 修改成员关系。

AW3 保存：军团角色、所属城市、任务、稳定旗手、战争计划索引和特殊军团策略。AW3 不反射写入原版 Army 的 captain、city、kingdom 或 units 字段。

旗手存活且仍符合军籍时不得替换。旗手死亡或失效后，由 AW3 选择候选，再调用原版统帅 API 完成变更。空军团和重复军团由有界清理队列通过原版移除入口处理。

## 4. 跨海运输

AW3 创建军团级运输意图，包含军团、出发区域、目标海岸、优先级和等待成员。每个 Actor 的实际请求使用原版 `TaxiManager.newRequest`，请求合并和合法性由原版 `TaxiRequest` 负责。

AW3 可以扩展哪些船型可承担 Taxi 请求，并决定运输任务优先于海战、何时造船和如何排队，但不能同时手工设置 `boat.taxi_request`、船任务和 TaxiRequest 状态。

同一 Actor 同时最多属于一个原版 TaxiRequest；同一船同时最多执行一个运输请求。取消、死亡、战争结束和目标变化统一调用原版取消/完成 API。

## 5. 城市占领

AW3 继续决定占领是否冻结、需要哪些有效军人、首次占领者、附庸占领归属和战争目标是否开放。进度自然达到完成条件后必须调用原版 `City.finishCapture`，所有权变更必须通过原版 `joinAnotherKingdom`。

原版完成后，AW3 在 postfix 阶段记录战时控制、战争分数、目标完成并唤醒下一城市任务。AW3 不直接复制原版占领完成步骤。

## 6. 调度和降级

RTS 战略阶段运行在原版 Army 更新之后，并遵守暂停、读档、联机客机和世界重置 gate。原版执行层不由 AW3 调度器再次调用。

路线规划、战争导演或运输分配发生异常时，只取消或降级对应 AW3 指令，Actor 和 Army 回到原版执行。异常不能启动第二套执行器，也不能暂停全局。

## 迁移检查点

1. Actor 移动执行权回归原版，保留战略路线建议。
2. Army 生命周期回归原版，保留 AW3 元数据和策略。
3. Taxi 状态机回归原版，保留军团运输意图和造船策略。
4. City 占领完成回归原版，保留 AW3 占领政策与战果记录。

每个检查点必须有独立设置或提交级回滚点，但最终运行时不能让同一状态同时由旧路径和新路径执行。

## 测试与验收

- 扩展现有 `ArmyRtsAdversarialSimulation`：10 城、20 军团、士兵分散、跨海和多战争场景。
- 验证集结后统帅才出发，士兵能持续跟随，攻下一城后立即获得下一目标。
- 验证陆海成本选择、无船造船、运输排队、军舰运输和完整下船。
- 验证旗手不闪烁、无重复 Army、无零人空壳长期残留、成员和统帅存读档一致。
- 验证已占城市只在原拥有者反攻时重新进入目标列表。
- 验证暂停、载入、联机 replica 和世界清理期间不推进 RTS 状态。
- 性能验证记录战争导演、路径请求、Actor batch、Taxi 和 GC 分配；功能正确性优先，不以降低调度频率掩盖挂机。
