# 逆夏化与胡化设计

## 目标

为城市人口文化增加与入夏化相反的长期演变。异族文化占优势且缺少夏人国家接触时，原生夏文化人口以及带有“入夏/完全入夏”特质的文化人口会逐年转入城市中占优势的未入夏文化。该机制只改变人口文化，不回滚国家制度入夏等级，也不删除任何文化特质。

## 判定

- 入夏人口：原生夏文化，或文化带 `aw_xia_integrated` / `aw_xia_fully_integrated`。
- 城市入夏人口占比低于 35% 时启动，已经启动后恢复到 40% 才停止。
- 低于 15% 时加速。
- 目标文化是城市人口最多的未入夏文化；并列时优先城市当前主文化，再按文化 ID 升序。
- 原生夏国完全阻止逆夏化。边境、外交、附庸、官员和通婚等真实接触提供累加保护；单纯占领夏地不提供保护。
- 空城、已销毁城市和土匪寨子不处理。

## 速度与结算

- 15% 至 35%：每年转换当前入夏人口的 2%。
- 低于 15%：每年转换当前入夏人口的 5%。
- 数量乘以接触保护系数，小数余量保存在城市数据中，使小城市也能长期推进。
- 人物转换复用原版 `Actor.tryToConvertToCulture(Culture)`，保留高级记忆和不可转换文化检查、统计更新与特效。
- 当目标未入夏文化取得城市人口绝对多数时，调用原版 `City.setCulture(Culture)` 更新城市主文化。

## 调度与持久化

- 从现有 `KingdomAnnualWorkService` 的年度政策阶段调用，每个王国只遍历自己的城市，不增加逐帧或全图扫描。
- 活跃状态、目标文化 ID、小数余量、最后处理年份和里程碑标志写入 `City.data`，随存档保存。
- 只记录“开始逆夏化”和“城市主文化转变”两个城市编年史里程碑，不记录每个人物转换。

## 非目标

- 不降低国家入夏制度等级。
- 不删除或修改文化本身的入夏特质。
- 不实现异族入关事件。
- 不修改语言、宗教、家族或血统。
