# 王国舆图设计

## 目标

在王国窗口“王国编年史”按钮下增加“王国舆图”入口。舆图按城市建立/易主事件生成历史节点：每个节点对应一页 PNG，展示该节点时事件双方的国家疆域、国家名称和海岸/双方边界线，并在右侧显示双方国家该年份的编年史。PNG 是主要导出格式，GIF 是由同一批节点帧生成的次要格式。生成结果写入当前存档目录，并可按最后完整节点增量继续。

本功能不在生成过程中采样实时战争、军队、地图模式或 Unity 世界对象。所有节点由已持久化的城市归属事件与 city zone 几何归档重建。

## 范围与非目标

### 范围

- 每个节点只包含发生城市归属变化的两个国家：失主和得主。
- 读取已有 `CityHistory` 中的 `city_found`/`city_transfer` 事件，按 `(world_time,event_id)` 排序。
- 使用新 map mode 的国名布局、字号、颜色、描边和可读性规则。
- 地图预览支持缩放与拖拽；窗口支持已有的宽窗口拖动和调整大小。
- 提供可选分辨率、PNG 生成、GIF 生成、数字百分比进度和增量续生成。
- 每个节点在右侧显示事件年份、城市归属变化，以及双方王国当年编年史事件。

### 非目标

- 不显示军队、军队位置、箭头、战线、城市标记、城市名称、人口、经济或其他 RTS 信息。
- 不在每个节点重新读取 `World.world`、`City.zones`、军队、地图模式或实时战斗状态。
- 不改变原版地图模式、战争逻辑或城市归属逻辑。
- 不为历史节点伪造缺失的 zone 几何或国家颜色。

## 数据模型

### 城市归属事件

复用 `CityHistory`，不重复建立归属事件表。事件主键为 `event_id`，时间排序键为 `world_time`。节点只接受：

- `city_found`：建立初始归属；
- `city_transfer`：旧国到新国的归属变化。

同一事件只生成一次。事件双方从事件快照中读取，不能从当前活跃 Kingdom 推断。

### City zone 几何归档

新增舆图所需的持久化几何索引，至少包含：

- 城市 ID、几何版本；
- zone 的稳定坐标/索引；
- zone 的地形/水域信息；
- 用于绘制海岸线和国家边界的相邻关系或等价边界信息；
- 城市名称和中心点的历史快照（仅用于节点信息，不在地图上绘制城市名）。

几何归档在城市创建、`City.addZone`、城市销毁和存档边界维护；不得按帧扫描。生成器仅读取已落盘归档。旧存档没有几何归档时，窗口显示缺失原因并禁止静默使用实时数据；完成一次归档建立后才能生成。

### 节点模型

每个节点包含：

- `event_id`、`world_time`、年份、城市 ID/名称；
- 失主和得主的 Kingdom ID、历史名称、历史颜色；
- 根据归属事件重放得到的双方 zone 集合；
- 双方当年王国编年史事件；
- 几何版本和渲染分辨率。

## 历史重放

`KingdomAtlasReplay` 先从几何归档建立“城市 -> zone 集合”索引，再按事件时间顺序重建城市 owner。节点只把失主和得主保留为可见 owner，其余 owner 的 zone 输出为空/背景，不参与国名和边界绘制。

同一城市在同一时间点的多条事件按 `event_id` 稳定排序；重复事件以 `(event_id)` 去重。事件节点完成后不得修改已生成节点的 owner 结果。

## 颜色规则

国家颜色必须是该历史节点时点的颜色，不能直接使用当前实时 Kingdom 颜色。解析优先级为：

1. 城市事件的 `context_kingdom_color`/`kingdom_color` 快照；
2. 同一节点该国王国编年史的 `subject_color`/`context_kingdom_color` 快照；
3. 存档中的王国档案颜色。

如果没有可靠颜色，节点生成失败并显示诊断信息，不用随机色、默认色或当前实时色替代。输出中的颜色变换只允许复用新 map mode 已定义的暗化/描边规则，不能改变国家之间的身份对应关系。

## 栅格与国名渲染

`KingdomAtlasRasterizer` 使用 CPU 像素栅格化：

- 国家 zone 使用该国历史颜色填充；
- 与水域相邻的外缘绘制海岸线；双方相邻边界使用 map mode 的边界描边规则；
- 非双方区域不绘制国家颜色、国名或其他对象。

`KingdomAtlasLabelRenderer` 复用新 map mode 的：

- 国家区域面积和连通块计算；
- 标签中心点、旋转角、可容纳字号和长名称缩放；
- 国名字体、颜色、描边和缩放规则。

输出 PNG 时将相同文字规则离屏栅格化到图像；不复用运行时 Text GameObject 的位置状态。地图中只绘制两个国家名称。

## UI 与交互

### 入口

在 `KingdomWindow` 右侧“王国编年史”按钮下创建“王国舆图”按钮，打开新的 `KingdomAtlasWindow`。窗口使用 `WideWindowChrome`，不重复实现窗口拖动/调整大小。

### 窗口布局

- 左侧：节点导航、地图预览和缩放/拖拽视口；
- 右侧：节点年份、城市易主信息、失主/得主名称，以及双方该年份王国编年史；
- 顶部或底部：节点上一页/下一页、分辨率选择、PNG 生成、GIF 生成、继续生成状态和数字进度。

地图预览支持滚轮缩放、按住拖拽平移，并在切换节点时保留合理的缩放比例和居中策略。窗口关闭不取消后台生成；只有显式取消才停止。

### 编年史筛选

双方王国事件从历史归档读取，使用与现有 `HistoryQuery` 相同的 `world_time` 转年份规则。右侧只显示该节点年份的事件，按 `world_time,event_id` 升序；没有事件时显示本地化空状态。

## 生成与持久化

### 输出目录

当前存档目录下创建 `aw3_kingdom_atlas`。每个分辨率生成独立输出集，避免覆盖旧图。文件名包含王国 ID、分辨率、节点序号和事件 ID，便于恢复和诊断。

### Manifest

manifest 至少记录：

- 世界/存档标识、王国 ID；
- 几何版本或几何哈希；
- 分辨率、输出格式和生成时间；
- 节点总数、已完成节点数；
- 每个节点的 `event_id`、年份、双方 Kingdom ID、PNG 文件名；
- 最后一个完整节点的游标。

增量幂等键为 `(event_id,resolution,geometry_version)`。生成前读取 manifest，已完成节点跳过；分辨率或几何版本改变时建立新输出集。每写完一张 PNG 就原子更新 manifest 和进度游标，崩溃/取消后只从最后完整节点继续。

### PNG/GIF

PNG 是主流程，每个节点一张图。GIF 生成复用已经完成的同分辨率像素帧，不重新重放历史或读取实时世界。GIF 写入失败不删除已完成 PNG，并在窗口显示失败原因。

### 分批与进度

事件排序、归属重放和 CPU 栅格化按批次执行；Unity 字体纹理工作仅在主线程按预算分批执行。窗口显示 `已完成/总数（百分比）`，并显示当前阶段：读取、重放、栅格化、写 PNG 或编码 GIF。

## 错误与恢复

- 当前没有存档目录：禁用生成并提示先保存世界。
- 历史归档不可用：禁用生成并保留错误诊断。
- city zone 几何缺失/版本不一致：拒绝生成，不使用实时数据替代。
- manifest 损坏：验证文件后重建节点索引，但保留已有 PNG；无法验证的文件不计入已完成节点。
- 磁盘写入失败：保留最后完整游标，显示失败节点和错误；下次可继续。
- 显式取消：停止后续节点，已完成 PNG 和 manifest 保留。
- 世界切换或读档：清理当前窗口上下文，避免把不同世界的几何/事件混用。

## 组件边界

- `KingdomAtlasHistoryQuery`：历史事件和年度王国编年史查询。
- `KingdomAtlasGeometryArchive`：city zone 几何归档读写与版本校验。
- `KingdomAtlasReplay`：城市 owner 历史重放和双方筛选。
- `KingdomAtlasRasterizer`：疆域、海岸线和边界像素绘制。
- `KingdomAtlasLabelRenderer`：复用 map mode 规则进行国名离屏绘制。
- `KingdomAtlasArtifactWriter`：PNG/GIF、manifest、原子写入和增量游标。
- `KingdomAtlasWindow`：入口、预览、导航、控制项和进度展示。

这些组件之间只传递不可变节点模型或像素帧；生成器不依赖军队、战争导演或实时地图模式。

## 测试与验收

### 规则测试

- 事件按 `world_time,event_id` 稳定排序并去重；
- 城市 owner 重放在多次易主和同年多事件下正确；
- 节点只保留事件双方，其他国家不产生颜色或国名像素；
- 颜色优先级使用历史快照，缺色会拒绝生成；
- 增量游标、重复生成和分辨率切换符合幂等键；
- 几何版本变化会建立新输出集；
- 国名布局结果与新 map mode 规则一致；
- PNG 帧尺寸、像素边界和 GIF 编码可被验证读取。

### UI/运行验收

- 王国窗口按钮位置正确且能打开舆图窗口；
- 舆图窗口可拖动、调整大小，地图可缩放和拖拽；
- 右侧每个节点显示双方当年编年史；
- 生成过程中进度百分比持续更新，取消/重启后从最后完整节点继续；
- 生成期间不读取实时军队或地图模式状态；
- 保存、读档、世界切换后不会混用历史归档；
- Release 构建、规则测试和 PNG/GIF 文件完整性测试通过。

## 实施顺序

1. 增加 city zone 几何归档模型、schema、版本和存档边界维护。
2. 实现历史事件查询、节点模型、owner 重放和年度编年史查询。
3. 抽取/复用新 map mode 的国名布局规则，完成双方疆域 CPU 栅格器和离屏文字层。
4. 实现 PNG/GIF writer、manifest、增量游标和进度回调。
5. 实现 `KingdomAtlasWindow`、入口按钮、缩放拖拽预览和节点导航。
6. 添加规则/UI/文件输出测试，执行 Release 构建和运行验收。
