# 官场分层人口与经济统计面板设计

## 目标

在中央官场、州首府地方官署和普通地方官署中增加统一的“统计”按钮，打开同一套统计面板，并按当前官署层级限制统计范围。

## 统计范围

- 中央官场：当前国家全部存活城市。
- 州首府地方官署：当前州法理的全部成员城市；如果当前城市不是州首府，则只显示本郡统计。
- 普通地方官署：当前郡/城市本身，不读取其他州或全国数据。

如果州法理不存在或无法解析，地方官署回退到当前城市统计，不能把全国数据误显示为州数据。

## 指标

统计面板固定展示：人口、城市数、税值、政策点、科技点、人力、粮食稳定、治安风险。人口来自城市实时人口接口；经济指标来自 `CityEconomyService.GetSnapshot(City)` 的持久化年度快照。没有经济记录的城市按零值显示，并保留“暂无年度记录”状态。

## 架构

新增只读统计服务，将城市集合聚合为不可变的统计快照。服务不创建数据库记录、不触发年度经济计算，也不修改官场或州法理缓存。中央和地方窗口只传入当前国家、城市和官署层级，统计面板复用同一 UI 组件。

统计结果按窗口打开时计算一次；面板刷新时重新计算。这样避免 Update 中重复枚举城市和重复 SQL 查询。

## 失败处理

- 无效国家、死亡城市或空城市集合：返回全零快照和明确的“无可用统计”状态。
- 州法理读取失败：回退当前城市范围，并显示“州法理不可用”的提示。
- 单个城市经济快照读取异常：跳过该城市经济值，但人口仍计入。

## 验证

规则测试覆盖中央、州、郡三种范围选择，以及州法理缺失回退；源码守卫确认所有入口使用同一个统计面板和 `CityEconomyService.GetSnapshot`。
