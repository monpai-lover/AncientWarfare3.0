# 州法理临时首府与连续州域设计

## 目标

修复国家国内州地图的两个浏览错误，并统一新城、旧存档修复时的州法理分配规则：

- 法理首府不受当前国家控制时，国内州地图把州名显示在该国控制范围内的临时首府。
- 从附庸国进入州法理地图时保留附庸国上下文，不再跳回宗主国。
- 每州最多六城，且同州城市必须通过同州成员连续接壤，不允许州法理飞地。

## 视图上下文

全图州模式继续按法理首府显示州名，不改变州法理身份、名称和全局锚点。

进入某个国家的国内州模式时，视图上下文使用玩家实际点击的国家 ID。附庸国不会被转换为宗主国或层级代表国，因此可直接查看附庸国控制的州成员。

国内州模式通过现有 `EffectiveSeatCityId` 选择标签与点击锚点：

- 当前国家控制法理首府时，有效首府就是法理首府。
- 法理首府失控时，从当前国家控制的该州成员中按现有有效首府规则选择临时首府。
- 临时首府只影响当前国家视图，不修改 `LegalSeatCityId`、州名、战争目标或持久化法理定义。

## 连续州域规则

一个有效州最多包含六个城市。除单城州外，每个成员城市都必须能沿同州且互相接壤的城市链到达州首府。

为新城市或未归州城市分配州法理时按以下顺序处理：

1. 收集与该城市直接接壤、当前少于六城的州。
2. 优先选择与该城市共同边界最多的州。
3. 共同边界数量相同时，选择距离州首府最近的州。
4. 仍相同时使用稳定的州 ID 排序，保证读档后结果一致。
5. 没有符合条件的接壤州时，以该城市建立新州。

不得仅因地理距离较近而跨越空隙加入不接壤的州。

## 旧存档修复

旧存档维护需要同时执行容量和连通性校验。每个州以法理首府所在的连通分量为主体；不在主体内的飞地城市重新按上述分配顺序加入相邻且未满六城的州，无法加入时建立新州。

如果法理首府城市已经不存在，则先按现有合法首府恢复规则确定主体锚点，再处理飞地。修复过程必须稳定、幂等：连续运行不会反复迁移城市或改变已合法的州。

## 数据边界

- 法理身份始终使用州 ID 和 `LegalSeatCityId`。
- 国家国内视图的标签锚点使用 `EffectiveSeatCityId`。
- 附庸关系不改变城市的物理控制国，也不改变国内州视图的国家焦点。
- 修复州成员后刷新州法理地图、法理战争目标和地方官署聚合；单纯切换浏览上下文不写存档。

## 回归测试

- 法理首府被外国控制时，国内州标签锚定本国有效首府。
- 全图州模式仍锚定法理首府。
- 点击附庸国后，焦点国家 ID 保持附庸国 ID，并可进入其州视图。
- 新城只加入直接接壤且少于六城的州。
- 多个候选州按共同边界、首府距离、稳定 ID 依次决胜。
- 相邻州已满或没有相邻州时创建新州。
- 旧存档飞地被迁出，合法连续州保持不变。
- 修复结果满足每州不超过六城、州内连通且重复运行不再变化。
