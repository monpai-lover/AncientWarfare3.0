# 经典文明种族寿命统一设计

## 目标

将原版 `human`、`elf`、`dwarf` 的基础 genome `lifespan` 统一设为 `70f`。

## 边界

- 只修改三个原版 ActorAsset 的 genome 基础值。
- `human` 原本已经是 `70f`，仍显式归一化，防止其他内容覆盖。
- `elf` 从原版 `500f` 调整为 `70f`。
- `dwarf` 从原版 `220f` 调整为 `70f`。
- 不修改 `orc`、`Xia`、猴族或其他生物。
- 不清除特质、装备、状态、科技对最终寿命的正常加成。
- 初始化必须幂等，并在原版 ActorAsset 已注册后执行。

## 测试

- 三个目标种族均被设置为 `70f`。
- 非目标种族不进入修改列表。
- 初始化入口存在且位于原版 ActorAsset 可用之后。
- 不对 `base_stats` 叠加第二份寿命，避免 genome 与 base stats 重复计算。

不编译主模组 DLL。
