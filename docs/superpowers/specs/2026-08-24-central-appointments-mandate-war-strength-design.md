# 中央任官、天命战争与军力增强设计

## 目标

本计划收敛四类相互影响的行为：中央与地方官职互斥、可任官候选人重复扫描、帝国接壤战争的割地优先、天命战争的直接占地，以及天命国家军力不足。州法理标签的首府锚定和刷新作为相关显示边界一并固化，避免战争或官署变更后出现错误聚合。

## 设计原则

- 复用现有 Court、WarTerritory、WarTerminalSettlementCoordinator 和地方官署流程，新增小型规则服务作为边界，不重写大方法。
- 任命、战争结算和军力计算使用明确的事务边界；失败时不留下半任命或半结算状态。
- 缓存只保存候选快照，不永久保存职位资格；选择前始终进行实时资格校验。
- 天命军力加成只作用于有效军力、动员和补员，不直接增加城市人口。
- 不恢复或覆盖工作区中与本计划无关的性能文件删除和用户修改。

## 任官流程

### 中央任命

任命中央职位前，检查目标 actor 当前职位。如果 actor 任职于地方官署，先完成地方卸任、写入地方任职结束历史、释放职位占用，再写入中央任职开始历史。整个过程保证 actor 不会同时占据中央和地方职位。

地方职位空缺立即进入自动补缺队列。补缺顺序固定为：

1. 同一地方官署已有候选人；
2. 同一城市或同一州的可任官人员；
3. 全国候选字典中的合格人员。

地方候选不足时允许从地方直接提拔到中央，仍使用同一卸任和历史记录事务。普通制度复用 `ValidateOfficers + EnsureMinimumCourt`；西式制度保留现有选举队列。

### 候选人字典

新增运行时 `OfficerCandidateCatalog`，按国家、官署范围和候选来源保存 actor ID 快照。首次需要补官或首次进入世界时完整扫描，后续从快照筛选，选择前重新验证存活、国籍、职位占用、仕途等级、品级和其他动态资格。

actor 死亡、改国籍、任官、卸任、资格变化、读档或切换世界时执行增量失效或懒清理。中央、地方和科举候选共用快照，避免重复扫描全体人口。

## 和谈与战争

### 帝国接壤割地优先

帝国级国家与对手存在实际接壤时，无论攻守方均提高合法割地候选优先级。候选顺序为已占领目标城市、具有核心/法理/宣称依据的边境城市、其他合法割地城市，最后才回退朝贡、臣属或赔款。现有割地合法性校验不被绕过；没有合法候选时不得凭帝国身份强割无依据城市。100 分强制结算同样使用该顺序。

### 天命战争直接占地

`WAR_TIANMING / GOAL_TAKE_MANDATE` 与逐鹿战争归入直接领土转移战争。占领城市后立即转移国家归属，刷新州法理、地方官署聚合、战争目标进度和编年史；达成目标后立即结束战争，不进入普通和谈。天命国优先选择天命战争理由，不可用时才回退其他合法理由。攻方全灭、目标首都失守等既有终止条件仍通过统一终止协调器处理。

### 天命首都失守与核心环转移

天命战争中，开战时记录的天命首都作为固定目标。该首都被敌方占领并确认转移后：

1. 占领者立即获得天命；
2. 将原天命首都和原天命实际控制、且与首都直接相邻的一圈法理核心城市一并转移给新天命；
3. 已被第三方控制、非原天命法理核心或已毁灭的城市不强行转移；
4. 统一刷新州法理、地方官署聚合、战争目标、地图和编年史，保证重复触发幂等；
5. 天命战争立即结束，不再进入普通谈判。

“一圈”使用现有城市相邻关系/边界索引的一跳邻接，不使用全图半径扫描；若首都在战争期间迁移，仍以开战时记录的首都为目标。

### 逐鹿战争性能边界

逐鹿战争保留相邻优先和逐鹿吞并语义，但不再允许每个国家在每轮 AI 中枚举全世界所有国家。候选目标使用可配置上限（默认 24），先取直接相邻、天命目标和最近的有限候选；`WarCandidateLimit` 不得在逐鹿模式返回无界值。每月逐鹿导演建立一次有界宗主树和军力快照，战争创建、城市转移或附庸变化才使快照失效，避免同一月份重复计算。

活动逐鹿战争使用按攻击方、声明防守方和战争 ID 的运行索引，替代城市占领时遍历全部战争；`HasActivePrincipalWars`、对垒捕获判断和终止结算都从索引读取。逐鹿战争、RTS 军队生命周期、地图刷新和编年史写入均采用每周期预算，超过预算的工作排队到下一周期，不能在一个大步长中集中执行。地图只刷新受影响城市和州，不调用无界 `DirtyAllMaps`。

逐鹿战争全局和单国活动战争数设置上限；达到上限时保留已存在战争，只暂停新的宣战尝试。性能诊断记录候选枚举数量、战争索引命中率、每周期结算工作量和地图刷新数量，用于验证卡顿是否来自逐鹿链路。

### 自建天命与治乱阶段

任何成功建立天命（包括玩家自建、复国、逐鹿夺取）都必须同时刷新天命面板阶段和逐鹿运行标记。建立成功后沿用现有 `OnMandateEstablished` 的 `Renewal` 阶段，清除旧的 `Chaos` 状态；如果世界仍处于逐鹿运行状态，则关闭逐鹿导演持久标记，避免新天命建立后继续显示“群雄割据”并重复执行逐鹿选王。读档时同时校正面板阶段和逐鹿标记，防止一边恢复而另一边残留。

## 天命国军力

新增集中式 `MandateMilitaryStrengthRules`：

- 有效军力默认系数 1.5，可配置；
- 后备兵动员效率默认系数 1.25，可配置；
- 战争补员提高优先级和速度，但受城市库存、粮食、战争预算与冷却限制；
- 选将优先高仕途等级和高战斗属性人员；
- 和平时期不产生无限刷兵，不改变城市人口统计。

所有加成只在战争军力评估、动员和补员流程生效，并通过单战争预算和上限防止滚兵与性能恶化。

### 军队重整前置条件

军队进入重整或补员任务前，必须先读取所属城市或国家的后备兵员池，并确认可补人数大于零。后备兵员为零、后备池不存在或候选补员数量为零时，禁止创建或重复刷新重整任务，不得凭空增加军队人数。此时根据战争状态转入撤退、待命或继续战斗；任务状态记录为“无可用后备”并带有冷却，避免每个调度步重复尝试。后备兵员恢复后，下一次有界检查才允许重新进入重整。

### 天命国紧急征兵

天命国野战军低于编制时，目标编制按 900 人封顶计算；只有当前人数低于目标时才进入紧急征兵。征兵必须调用原版 `City.makeWarrior(actor)` 入口，由原版城市征兵流程提供 actor，不新增全世界 actor 扫描器、不重复维护另一套全体人口候选列表。天命国的征兵条件在该入口层放宽到可用的成年本国居民，允许将更多可征人员直接转为 `warrior`，但仍排除国王、继承人、城市首领、禁卫军、现役其他军队成员、婴儿和已死亡 actor。

征兵按城市和军队的原版批次节流执行；每批结束重新读取军队人数和后备可用量。达到 900、没有更多原版候选或后备兵员为零时立即结束本次征兵，并写入原因，不重复创建重整任务。该流程不通过伪造人口或无界合成人数来填满军队。

## 州法理显示边界

全图州模式始终在法理首府 `city_center` 显示州名。国内州模式在首府失守时，按人口、发展度、城市 ID 稳定选择本国控制成员作为临时首府。禁止使用整州质心，也禁止因点击空地重建法理。新城市加入最近有效法理首府所属州，州最多 6 个城市；旧存档无州区域使用发展度最高城市创建首府。首府改名同步州名，州撤销后地图保持空白。

## 数据与错误处理

- 任官事务任一步失败时回滚职位占用和历史写入，避免中央已任命而地方仍显示占用。
- 直接占地重复触发时按战争 ID、城市 ID 幂等处理。
- 候选字典中的失效 actor 在读取时清除，不阻塞补官流程。
- 天命军力加成读取异常时回退普通军力，避免战争系统崩溃。

## 验证范围

增加规则和源码守卫测试，覆盖：中央任命先卸任地方、地方即时补缺、同一 actor 不重复任官、帝国接壤割地优先、天命战争直接转移并结束、天命首都失守时核心环转移、自建天命清除群雄割据运行标记、天命紧急征兵调用原版入口并最多补到 900、天命军力不改变人口、逐鹿候选有界、逐鹿战争索引不遍历全局、达到战争上限时不继续创建新战争、无原版候选或无后备兵员时不进入重整循环、后备恢复后可重新重整、州法理首府和临时首府显示、存档读写后的幂等恢复。

## 非目标

本计划不恢复当前工作区已删除的性能文件，不重写 RTS 寻路，不改变普通战争的合法割地校验，也不在本阶段扩展新的 UI 设计。
