# 逐鹿战争首都突破扩张设计

## 目标

当进攻方在逐鹿战争中占领敌方首都时，加快战争推进：把敌方首都所属法理州内的敌方城市，以及与该首都直接接壤的敌对参战国城市，一次性转移给首都占领方。逐鹿战争中占领任意法理州的州府时，也把该法理州内的敌对参战国城市一次性转移给州府占领方。

该规则只服务逐鹿战争，不改变普通战争、RTS 军队移动、登陆运输或常规城市占领速度。

## 触发条件

结算入口沿用现有城市占领完成链。只有同时满足以下条件才触发：

1. 当前战争是活动中的逐鹿战争。
2. 被占领城市是逐鹿战争声明的敌方首都。
3. 占领方是该城市的新控制者，并且仍是战争中的进攻方或其合法主攻方。
4. 该城市尚未执行过本次逐鹿战争的首都突破扩张。

州府突破使用同一结算链，但以州府城市 ID 作为幂等范围键；它不要求城市是国家首都，只要求城市是稳定法理州的首府。首都突破同时包含州府转移和首都邻接转移。

城市转移必须通过现有 `WarTerritoryService`/城市转移服务完成，不能直接写入 `city.kingdom`。

## 扩张范围

### 法理州范围

- 从被占领首都读取稳定的法理州标识。
- 选择该法理州内的全部有效城市。
- 城市当前所有者必须是逐鹿战争中的敌对参战国。
- 法理州规划不因当前占领状态改变；读取的是存档中的法理归属，而不是临时实际控制边界。
- 州府被占领时，州内全部敌对参战国城市进入候选集合；州府本身已被占领，不重复处理。

### 首都接壤范围

- 读取首都的直接城市邻接关系。
- 选择与首都直接相邻的有效城市。
- 城市当前所有者必须是逐鹿战争中的敌对参战国，即使该城市属于其他敌方参战国也允许纳入。
- 不递归扩展到邻接城市的邻居，不按距离或整片领土扩张。

### 明确排除

- 首都占领方自己的城市。
- 进攻方盟友或同阵营参战国的城市。
- 中立国和未参加该逐鹿战争的国家城市。
- 土匪寨、特殊不可转移城市和已销毁城市。
- 已在本次结算中转移的城市。

法理州范围和首都接壤范围合并去重，首都本身不重复处理。

## 结算流程

1. 在州府或首都占领完成后创建一次性突破上下文，记录战争 ID、突破城市 ID、占领方 ID 和突破类型。
2. 解析声明防守方和战争双方，建立敌对参战国集合。
3. 按法理州收集候选城市；若突破城市是国家首都，再追加首都直接邻接关系。
4. 对候选城市逐一执行现有城市转移服务。
5. 每次成功转移都复用现有历史、城市编年史、舆图和法理刷新回调。
6. 全部处理结束后写入突破完成标记和转移统计。
7. 若单个城市转移失败，记录错误并继续处理其他候选城市；不得回滚已经成功的城市。

## 幂等与安全

- 使用战争 ID + 首都 ID 作为幂等键。
- 在运行时状态和持久化数据中均记录已处理状态，防止存档重载、重复 `finishCapture` 或多个 Harmony 回调重复吞并。
- 执行前再次验证战争仍然有效、首都新所有者未改变、候选城市仍属于敌对参战国。
- 不修改普通战争的占领速度、战争分数、RTS 目标排序或运输任务。
- 城市转移服务失败只影响该城市，不阻塞逐鹿战争后续结算。

## 测试设计

规则测试至少覆盖：

- 首都占领触发扩张，普通城市占领不触发。
- 州府占领触发州内转移，非州府普通城市占领不触发州内转移。
- 法理州内敌方城市被纳入。
- 首都直接相邻的其他敌对参战国城市被纳入。
- 邻接城市的邻居不会被递归纳入。
- 盟友、同阵营、中立和未参战城市被排除。
- 法理州与邻接集合正确去重。
- 重复触发只执行一次。
- 单个城市转移失败时其余城市仍继续处理。
- 战争结束、首都易手或城市失效时不会执行扩张。

运行时验证包括：逐鹿战争存档重载、首都突破后的城市编年史和舆图刷新，以及普通战争和 RTS 登陆作战回归检查。
