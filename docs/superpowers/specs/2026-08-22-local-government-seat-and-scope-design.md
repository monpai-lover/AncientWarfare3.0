# 地方官署有效席位与模板作用域设计

## 背景

当前地方官署把法理州首府、当前国家实际控制的行政席位、城市地方官署主官混在同一条显示和任命链中。当法理首府被外国控制时，本国仍控制的成员城市无法生成州牧；中央官场和地方官署也会把固定主官当成普通职位过滤掉。自定义官府的应用入口还可能同时迁移中央与地方模板。

## 目标

1. 同一法理州被多个国家控制时，每个控制成员城市的国家都拥有独立的州级官署。
2. 法理首府被外国控制时，本国自动选择有效行政席位，并让该城市首领兼任州牧/都督及地方模板首席。
3. 州牧、都督和玩家模板中标记的州级主官使用固定动态卡片；普通下属官职继续由模板动态管理。
4. 中央模板和地方模板应用互不污染，整套应用只能由明确的组合入口触发。
5. 不破坏法理地图、地方官署历史、中央官场历史和旧存档。

## 设计

### 1. 法理席位与有效席位

每个地方官署读模型保留法理席位 `LegalSeatCityId`，并新增或等价计算当前国家的 `EffectiveSeatCityId`。

- 如果国家控制法理首府，`EffectiveSeatCityId` 等于法理首府。
- 否则从该国控制的法理成员城市中选择：人口最高，其次经济评分最高，最后 City ID 最小。
- 没有控制成员城市的国家不生成该州官署。
- 选择逻辑必须是纯规则函数，输入城市快照后得到稳定结果，读档和刷新不会随机漂移。
- 法理首府收复后，下一次刷新自动切回法理首府。

`RegionalGovernmentReadModel`、`LocalCourtReadModel` 和相关聚合缓存统一使用有效席位生成主官，但继续保留法理席位用于名称、地图和历史追溯。

### 2. 固定动态卡片

- 每个国家-法理州组合固定生成一个州级主官节点，即使主官空缺也显示卡片。
- 主官来源固定为有效席位城市的 `city.leader`。
- 地方模板首个主官职位绑定同一个 `city.leader`，避免州牧/都督和城市主官出现两个不同人。
- 默认模板：民州显示州牧，军府显示都督。
- 自定义模板：使用模板中明确标记为州级主官的职位名称；若未标记则使用地方模板首席职位作为显示名称。
- 主官死亡、城市易手、有效席位切换时立即刷新卡片；没有合格主官时显示空缺，不隐藏官署。
- 中央官场、州级官署和城市官署复用同一动态卡片数据结构和点击跳转行为。
- 其他同级和下属职位保持现有模板驱动的空缺、任命、任期和历史逻辑。

### 3. 模板作用域隔离

运行时将自定义官府分为两个作用域：

- `CentralCourt`：中央官职、中央层级、中央效果和中央任职历史。
- `LocalGovernment`：地方模板、州级主官、郡级官职、地方效果和地方任职历史。

应用行为：

- 地方窗口的“应用”只更新城市的地方模板 ID，迁移地方官职并刷新地方官署聚合。
- 中央窗口的“应用”只更新国家中央官场实例，迁移中央官职并刷新中央官场。
- “中央 + 地方全部应用”作为单独、明确的组合入口保留。
- 地方模板的州级职位只影响地方州级卡片，不向中央模板写入同名职位。
- JSON 导入导出保留同一格式兼容性，同时补充 `scope`；旧文件按内容自动识别并落入对应模板集合。
- 应用成功后只触发对应作用域的迁移和刷新，避免地方应用重置中央任职，或中央应用重置地方官署。

## 数据流

1. 法理区域服务读取所有成员城市及其当前控制国家。
2. 对每个国家筛选本国控制成员，计算有效席位。
3. 有效席位产生州级固定主官节点，并把城市首领映射到地方模板首席。
4. 地方官署任命服务补齐模板下属职位，中央任命服务只处理中央模板。
5. UI 使用统一动态卡片模型渲染中央、州级和城市节点。
6. 模板应用按作用域调用对应迁移服务并分别刷新缓存。

## 兼容与错误处理

- 旧存档没有有效席位字段时实时计算，不要求迁移存档。
- 法理州撤销、城市被毁或国家灭亡时清除对应运行时卡片和缓存，不删除官职历史。
- 有效席位计算失败时返回空缺卡片，不回退到外国控制的法理首府首领。
- 模板缺少州级主官标记时使用首席地方职位；模板无职位时保留空缺卡片。
- 作用域不匹配的导入文件拒绝应用并提示原因，不执行部分迁移。

## 测试

新增或扩展以下测试：

- 法理首府被外国控制时，按人口、经济、City ID 稳定选择有效席位。
- 同一州两个国家各自生成州级主官，互不读取对方首领。
- 有效席位切换后州牧/都督卡片和城市首席绑定同步切换。
- 主官死亡显示空缺卡片，补任后恢复同一固定卡片。
- 民州、军府和自定义州级主官名称正确显示。
- 地方模板应用不改变中央模板、中央任职和中央历史。
- 中央模板应用不改变城市地方模板、地方任职和地方历史。
- 组合应用才同时迁移两个作用域。
- 旧模板和旧存档加载后保持现有行为。

## 非目标

- 不改变法理州的创建、撤销和战争规则。
- 不改变官员候选筛选、任期年限和科举资格规则，除非固定主官绑定需要调用现有补缺入口。
- 不重做中央官场或地方官署的整体 UI，只替换主官节点数据来源并复用已有卡片。
