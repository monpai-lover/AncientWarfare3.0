# 入赘谱系与东方命名五族族谱设计

## 目标

建立全种族通用入赘继承，保证女性统治者的权力层级高于男方时，丈夫进入女方家系，双方子女继承女方的姓、氏支、谱系和原版 Clan。同时让狗、狐狸、柠檬人、兔子和乌龟在保持现有东方词库命名的前提下进入完整族谱。

## 已确认语义

- 入赘适用于所有能够产生女性城市 leader 或 king 的种族，不由命名档案或种族白名单限制。
- 权力层级为 `普通人 < 城市 leader < king`。女方当前层级严格高于男方时，双方关系视为入赘；同级不自动入赘。
- 入赘关系持久化到丈夫的 `MATRILOCAL_IN_LAW` 和 `MATRILOCAL_WIFE_ID`，不在每次出生时临时比较双方职位。
- 所有种族均使用同一套入赘来源选择规则；西方和猴族不得保留绕过通用规则的独立父系硬编码。
- 入赘婚姻的子女继承母亲的姓、氏支、谱系和原版 Clan。
- 普通婚姻继续父系优先；父亲没有有效谱系时才回退母系。
- 女王即位前已经出生的子女通过现有统治者晋升后代同步链路归入母系。
- 狗、狐狸、柠檬人、兔子和乌龟继续使用各自现有词库生成姓与名，不改成西方命名；它们进入与猴族相同的完整出生归档和族谱链路。

## 根因

### 西方姓氏

普通西方出生已经具备 `TryInheritLightweightWesternSurname`，但出生补丁的轻量路径只记录亲子边，没有调用该方法。高权女性即使拥有完整家系，父系优先选择也会在父亲存在时截断母系来源。后续角色晋升可能为子女新建按城市派生的家系，因此表现为父辈使用词库姓、子辈变成地名姓。

### 入赘状态

代码已有 `MATRILOCAL_IN_LAW` 与 `MATRILOCAL_WIFE_ID`，后代同步规则也会读取它们，但当前没有建立入赘关系的写入入口。猴族的 `ResolveInheritedFamily` 还明确只读取男性父母，进一步保证了女王姓氏无法传给子女。

### 东方命名五族族谱

五族使用 `NativeSinitic` 命名档案，但 `WesternLineageEligibilityRules` 当前明确将该档案排除在完整出生路径、谱系系统和亲子边所有权之外。它们拥有东方姓名，却没有可供族谱读取的稳定 `LINEAGE_ID`、`SHI_ID` 和完整出生归档。

## 设计

### 入赘关系建立

新增纯规则判定：女方和男方有效，且女方统治层级严格高于男方时，应建立入赘关系。权威运行时在统治者家庭关系建立、女性 leader/king 晋升后的家庭修复以及出生收口处执行幂等同步：

- 丈夫写入 `MATRILOCAL_IN_LAW=true`。
- 丈夫写入 `MATRILOCAL_WIFE_ID=女王 Actor ID`。
- 关系不因一次普通任务或显示刷新而丢失。
- 女性统治者死亡、退位或双方关系解除后的清理只影响未来出生来源；已经归档的子女不反向改回父系。

出生收口保留一次幂等兜底，以兼容旧存档中已有女性 leader/king 配偶但尚无入赘标记的状态。

### 出生谱系来源

统一来源选择顺序：

1. 父亲明确入赘当前母亲时，选择母亲。
2. 否则选择具有完整谱系的父亲。
3. 父亲没有有效谱系时，选择具有完整谱系的母亲。
4. 双方都没有完整谱系时，使用现有普通姓氏初始化，不凭空复制错误家系。

西方轻量出生必须在记录亲子边后调用既有姓氏继承逻辑。选中母系时直接复制母亲已经持久化的 `FAMILY_NAME`、`CHINESE_FAMILY_NAME` 和本地化姓组件，禁止重新调用城市/词库随机家系生成。

猴族把当前“只扫描男性父母”的取姓逻辑替换为同一来源选择规则。入赘时使用母亲姓；普通婚姻仍使用父亲姓；无可继承姓时才从猴族词库生成。

### 五族完整族谱

`NativeSinitic` 保持自身命名档案，但在谱系资格层视同猴族使用完整出生路径：

- 创建或继承稳定 `LINEAGE_ID` 与 `SHI_ID`。
- 通过 `LineageBirthArchiveService` 原子写入人物档案和父母边。
- `UsesAwLineageSystem` 对已有稳定谱系的 `NativeSinitic` 返回真。
- 家庭树入口和活人节点构建复用现有族谱规则。
- 姓名显示继续姓前名后，生成器仍是各物种现有的 `civ_*_name` 词库，不切换为猴族或西方生成器。

## 兼容与性能

- 不进行常驻全世界扫描。
- 入赘关系只在家庭关系变化、女王即位和出生事件处幂等更新。
- 旧存档在女王家庭首次刷新或下一次出生时补齐入赘标记。
- 五族只在原有出生事件中增加归档写入，不增加年度全量维护。
- 所有数据库写入继续经过现有出生原子归档服务，避免重复亲子边。

## 测试

- 西方词库姓父亲的普通子女继承同一个词库姓，不生成地名姓。
- 西方女性 leader/king 的入赘丈夫被正确标记，子女继承女方家系。
- 猴族女性 leader/king 的子女继承女方姓；普通猴族家庭仍父系优先。
- 其他种族在相同权力层级条件下使用同一通用入赘判定。
- 非入赘的普通高职位女性不越过有效父系。
- 五个 `NativeSinitic` 物种进入完整出生路径、稳定谱系与族谱节点。
- 五族姓名生成器和姓前名后规则保持不变。
- 重复出生回调、读档恢复和女王家庭刷新不会重复创建谱系或亲子边。

## 非目标

- 不为所有女性无条件建立母系继承。
- 不按每次出生时的动态职位高低拆分同一家庭的姓氏。
- 不改变西方、猴族或五族的现有词库内容。
- 不重做族谱 UI 布局。
