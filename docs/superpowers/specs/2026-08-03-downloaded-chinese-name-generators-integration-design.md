# 下载中文名称生成器整合设计

## 目标

把下载目录中的国家、人物和城市中文名称生成器整合进 AW3，同时保留 AW3 自有文化命名体系，不导入原版人类生成器，也不改变猴族当前使用的 AW3 专用生成器。

输入文件：

- `C:\Users\24908\Downloads\kingdoms.json`
- `C:\Users\24908\Downloads\creatures.json`
- `C:\Users\24908\Downloads\cities.json`

目标文件：

- `name_generators/default/kingdoms.json`
- `name_generators/default/creatures.json`
- `name_generators/default/cities.json`

## 合并规则

以生成器 `id` 为唯一键分别合并三类 JSON：

1. 下载文件中不存在于 AW3 的 ID 直接新增。
2. 下载文件中与 AW3 重名的 ID 使用下载版本完整替换，不拼接模板。
3. AW3 中存在而下载文件中不存在的 ID 原样保留，包括 `Xia_*`、`western_*`、`orc_nomadic_*` 和其他 AW3 扩展生成器。
4. `human_name`、`human_city`、`human_kingdom` 不导入，保留 AW3 当前定义。
5. `civ_monkey_name`、`civ_monkey_city`、`civ_monkey_kingdom` 是覆盖规则的明确例外：它们由 `CivMonkeyNamingContent` 运行时注册，下载版本不得写入默认 JSON，确保 AW3 运行时定义是唯一来源。

因此，“排除人类”只排除三个原版人类 ID。`Cultiway.EasternHuman_*`、`Rome_name`、`Arab_name`、`Russia_name` 等其他生成器仍按普通合并规则导入。

## 运行时路由

本次不修改 `AWCultureNamingTraditionRules` 的文化路由。猴族仍路由到 AW3 自有的三个 `civ_monkey_*` 生成器；夏人继续使用 `Xia_*`；人类西方文化继续使用 AW3 当前 `western_*`；游牧兽人继续使用现有 AW3 专用 ID。下载内容即使包含其他人类衍生命名生成器，也不得改写这三套专用路由或替换其生成器内容。新导入生成器由游戏或现有显式 ID 路由使用，不额外改变种族到生成器的映射。

## 词库兼容

下载模板引用了 `日本名字` 和 `天干地支`。AW3 已有递归加载的 `word_libraries/default/mobs/天干地支.txt`，但缺少 `日本名字` 兼容名称。扩展 `AWWordLibraryManager.InstallChineseNameLegacyAliases()`，在资源加载后补全：

- `日本名字`：直接复用现有 `日本名字下` 词库。下载模板的完整结构是 `{日本姓氏}{日本名字上}{日本名字}`，因此该别名表示名字下半段，不得混入姓氏。
- `天干地支`：优先保留已经加载的完整词库；仅在该词库缺失时，由现有 10 天干与 12 地支按六十甲子顺序生成 60 项兜底词库。模板中的 `family_name` 是生成结果标签，不是词库内部字段。

兼容别名只在目标词库不存在时安装，避免覆盖以后可能加入的正式词库。合并时去除空值和完全重复的词条；若任一来源缺失，记录限量诊断并继续加载其他命名资源。

## 数据完整性与失败处理

整合脚本或测试必须解析 JSON 结构后按 ID 操作，不使用字符串替换。实现应拒绝重复 ID、空 ID、空模板集合和无法解析的 JSON，并在写入前完成全部验证，避免留下半写入文件。

模板引用校验应扫描最终三个生成器文件，确认所有 `{词库}` 与 `{词库:字段}` 引用均可由现有词库、运行时参数或兼容别名解析。未解析引用必须使测试失败并报告生成器 ID 与模板内容。

## 测试与验收

- 最终生成器集合包含下载文件中除六个保留例外外的全部 ID；三个 `human_*` 保留默认 JSON 当前定义，三个 `civ_monkey_*` 不写入默认 JSON并继续由 AW3 运行时注册。
- 所有 AW3 独有生成器仍存在，且其模板内容不变。
- 除六个保留例外外，所有下载文件中的重名 ID 与下载版本结构一致。
- `日本名字` 和 `天干地支` 兼容别名能够生成非空名称，并支持下载模板所需字段。
- 最终三个 JSON 可被严格解析，不存在重复或空 ID。
- 所有最终模板引用均能解析，不出现缺失词库诊断。
- 猴族人物、城市和国家仍使用 AW3 当前 `civ_monkey_*` 命名内容。
- 夏人、猴族、人类西方文化和游牧兽人的现有路由测试保持通过，且分别解析到 AW3 当前专用生成器。

## 非目标

- 不修改文化识别、种族归类或生成器选择优先级。
- 不删除 AW3 当前生成器。
- 不整体替换三个目标 JSON。
- 不导入下载文件中的三个原版 `human_*` 定义。
- 不调整词库中的具体中文词条内容。
