# 学派谱系死亡节点持久化显示设计

## 目标

学派详情中的谱系永久显示所有曾加入学派的成员，包括已经死亡的成员；教师死亡后，其弟子节点仍保留在原有谱系关系中。

## 数据流

`SchoolMembership` 是成员关系的持久化来源。读取接口必须同时返回活动记录和已关闭记录，并保留成员 ID、教师 ID、代数、声望、开始年份、结束年份及结束原因。窗口优先使用当前 Actor 的名称；Actor 已被销毁时使用持久化快照或历史记录中的名称。

`HistoricalSchoolMaster` 记录继续作为历史先师来源。学派窗口将先师记录与成员历史记录按 Actor ID 去重，再按原有学派顺序和成员关系排序。

## UI 行为

死亡节点复用现有 `SchoolLineageRowView` 的灰色和死亡标签。教师不存在时仍显示持久化的教师名称；节点不再因为教师死亡而被过滤。没有可恢复 Actor 时，节点保持只读，避免调用人物窗口导航。

## 边界与兼容

- 不修改成员加入、关闭和死亡写入逻辑。
- 旧存档缺少历史名称时使用稳定的 `actor <id>` 回退文本。
- 重复成员记录只保留同一 Actor 的最新有效历史记录。

## 验证

- 规则测试覆盖活动记录和关闭记录合并、去重以及死亡成员排序。
- 运行学派相关测试和 Release 编译。
