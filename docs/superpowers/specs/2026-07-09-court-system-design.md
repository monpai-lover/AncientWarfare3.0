# AW3 官场与诸子百家系统设计

日期：2026-07-09

## 目标

在国家点出“官场制度”科技后，开启完整的官场系统。官场不是收藏面板，而是国家运行层：它影响科技、国策、决策、政体走向、城市治理、军队路线、天命稳定、附庸外交、战争倾向和历史记录。

系统需要模拟春秋战国式的“贤人入仕”和“诸子百家”派系竞争，同时保持 AW3 当前性能优化方向：所有核心计算走缓存、低频刷新和有限候选池，不做全世界实时扫描。

## 设计选择

采用“分层官僚制”方案：

- 中央官场使用真实 actor 任职，决定国家路线。
- 地方官署每座城市只保留 1-3 个实职地方官，其余地方官吏抽象为官署效率和地方学风。
- 军府复用现有大将、禁卫军、边军、奴隶军、多军队系统，不重复生成一套军事官僚。
- 监察系统低频检查腐败、地方失控、非法身份、继承风险、军阀风险和党派失衡。

该方案保留代入感和可玩性，同时避免“完整实体官僚”把 updateAge/updateYear 压垮。

## 解锁阶段

### 原始朝会

未研究官场制度前，国家使用简化的原始朝会。

原始朝会参与者：

- king
- 继承人
- 城主
- 将领
- 族老或贵族
- 少量隐士、巫祝、武人倾向

原始朝会不显示完整百家体系，只显示粗粒度倾向：

- 近臣
- 武人
- 族老
- 巫祝
- 隐士

原始朝会只给轻微 AI 权重，不触发复杂党争，不授予诸子百家 trait。

### 百家官场

新增科技：`aw_tech_official_court`，显示名“官场制度”。

建议前置：

- `aw_tech_writing`
- `aw_tech_rites_music` 或 `aw_tech_granary_accounting`

研究完成后：

- 王国 UI 显示“百家官场”入口。
- 开启中央官职、地方官署、军府汇总、监察。
- 可以招募贤人、游士、隐士、士人。
- 官员在任期间获得对应学派 trait。
- 官场派系开始影响 AI 研发、国策、决策和政体走向。

## 王国 UI 入口

现有国策/科技/决策区域保留四个小按钮，不再继续向这一行增加按钮。

在四个按钮下面新增一行宽按钮：

- 宽度对齐上方四个按钮的总宽度。
- 未解锁时显示“原始朝会”。
- 解锁官场制度后显示“百家官场”。
- 左侧显示官场或士人 icon。
- 右侧可显示主流学派小 icon 或官场效率颜色。
- tooltip 显示官场状态、主流学派、官场效率、当前正在影响的国家路线。
- 点击打开官场窗口。
- 如果国家没有启用 AW3 体制且未 Xia 化，只显示锁定状态和说明，不打开完整窗口。

这样官场作为独立国家层级系统被看见，又不会挤乱现有四按钮排布。

## 官职体系

### 中央官场

第一版固定 6 个核心职位：

- 丞相：主导政策、政体走向、政治点产出。
- 御史：监察腐败、压制地方失控、发现非法继承、奴隶国王、军阀风险。
- 司马：影响军队组织、战争倾向、边军和大将体系。
- 司寇：影响治安、奴隶制执行、抓捕、叛乱镇压。
- 司徒：影响城市经济、税收、人口、地方治理。
- 博士祭酒：影响科技点、学派传播、官场学派组成。

后续可扩展太傅、太尉、廷尉、少府、宗正等职位，但第一版不铺开。

### 地方官署

每座城市最多 1-3 个实职地方官：

- 城主/太守：沿用现有 city leader，作为地方主官。
- 司仓/田官：影响经济、粮食、发展度、税收。
- 司寇/县尉：影响治安、捕奴、叛乱风险、占领区稳定。

城市规模决定实职数量：

- 小城：只保留城主/太守。
- 中城：城主/太守 + 一个经济或治安官。
- 大城：城主/太守 + 经济官 + 治安官。

其他地方吏员不实体化，统一折算进城市官署效率和地方学风。

### 军府

军府不新增大量职位，而是汇总现有军事人物：

- 大将：拥有封地和特殊军队，保持军事贵族身份。
- 禁卫军将领：保护 king，不主动远征。
- 边军将领：驻扎边境，巡逻、筑墙、反击。
- 奴隶军将领：统领奴隶军，负责战场捕奴和奴隶军冲锋。

军府负责将这些人物转化为国家路线影响，不重复抢占普通官职。

### 监察

监察系统不要求每城实体御史。第一版以低频规则运行：

- 检查低能或失职官员。
- 检查 mad、奴隶、敌国未 Xia 化人物是否占据关键职位。
- 检查地方军阀、封地大将、边军过强风险。
- 检查党派长期过强导致的路线锁死。
- 检查非法继承、奴隶国王、共和/义军转制等国家异常。

御史职位会提高监察发现率和处理效率。

## 官员来源

官场优先使用真实 actor。

候选来源：

- 贵族、氏族成员、王族旁支。
- 城主、将领、有功绩者。
- 高管理、外交、军事、智慧相关属性的平民。
- 已 Xia 化的外族官员。
- 历史人物、名臣类人物。

人才不足时，低频事件生成真实 actor：

- 游士：随机学派，适合进入中央官场。
- 隐士：偏道家、阴阳家、名家，能力高但不稳定。
- 士人：偏儒家、法家、墨家、农家，适合地方官署。
- 兵家门客：战争中更容易出现。
- 纵横策士：外交紧张、附庸体系复杂、宣称冲突多时出现。

这些人物不是 UI 卡牌，而是进入世界的真实 actor，并写入个人历史。

## 任官规则

AI 自动任官：

- 按职位需求评分，不只看总属性。
- 中央官优先高能力、高名望、高学派适配。
- 地方官优先本城或本国 actor，减少频繁迁移。
- 军府只读取现有军职，不强行抢人。
- 监察可弹劾低能、腐败、madness、奴隶或未 Xia 化敌国人物。

玩家手动任官：

- 在官场 UI 中选择职位和候选人。
- 可以任命、罢免、调任、扶持学派。
- 第一版不做重政治点惩罚。
- 罢免重要人物、任命名臣、核心职位更替会写入人物传记。

## 学派体系

第一版做完整百家雏形，但分主次。

完整效果学派：

- 儒家：礼制、天命、稳定、继承合法性、贵族秩序。
- 法家：律令、集权、税收、治安、强制改革、军国效率。
- 道家：休养生息、低干预、降民怨、降扩张欲望、减内乱。
- 墨家：守城、工程、民生、防御战争、城墙箭塔。
- 兵家：军队质量、撤退、战争目标选择、边军和大将效率。
- 纵横家：外交、附庸、联盟、宣称、议和、强宣惩罚降低。

基础效果学派：

- 农家：粮食、人口、城市发展度、税收下限。
- 阴阳家：天命、灾异解释、年号、祥瑞、正统叙事。
- 名家：法律争议、宣称论证、外交辞令、政策成本小幅波动。

## 学派 trait 规则

只有当前在官场、地方官署、军府、监察系统内的人，才持有学派 trait。

- 入官时添加对应学派 trait。
- 离官、罢免、死亡、叛逃时移除官场学派 trait。
- actor 可保留隐藏的天生学派倾向字段，但 trait 只在任官时显示。
- 这可以避免世界上到处都是学派 trait，也减少 trait/status 维护成本。

可以复用现有学者 icon 和 trait 资源：

- `iconRujia.png`
- `iconfajia.png`
- `icontao.png`
- `iconmo.png`
- `iconbinfa.png`
- `iconzonheng.png`

## 派系组成

每个国家维护一份 `CourtState` 缓存：

- 各学派人数。
- 各学派影响力。
- 当前主流学派。
- 第二学派。
- 派系集中度。
- 官场效率。
- 最近一次刷新年份。

影响力不是 UI 打开时现算，而是在官场刷新时写入缓存。官场窗口、AI、tooltip 都只读缓存。

影响力权重：

- 中央官最高。
- 城主和地方实职官中等。
- 军府人物只影响军事路线。
- 监察官影响稳定和纠偏。
- 名臣、历史人物、有高功绩者加权。
- king 的个人倾向给小幅加权，但不直接决定官场。

## 政体走向

官场不立即强制改政体，而是提供路线压力。

- 儒家长期强势：礼制、封建、天命正统、宗法继承更稳。
- 法家长期强势：律令制、集权、帝国制、废封建、强化税兵。
- 道家长期强势：低干预、休养、减少扩张和税负、民怨下降。
- 墨家长期强势：守城、边防、民生工程、防御性国家。
- 兵家长期强势：军功、军府、大将、边军、主动战争。
- 纵横家长期强势：附庸、联盟、复国战争、宣称和议和更活跃。
- 农家长期强势：农业国家、城市发展、人口恢复。
- 阴阳家长期强势：天命叙事、祥瑞灾异、正统合法性。
- 名家长期强势：宣称、外交辞令、法理争议、政策辩论。

## 软影响与强事件

采用混合控制：

- 平时是软影响。
- 一派长期强势或国家危机时触发强事件。

软影响包括：

- 调整 `KingdomPolicyAI` 研发权重。
- 调整常态决策选择。
- 调整战争目标、附庸、扩张、迁都、称天命评分。
- 调整政治点、科技点产出。
- 调整部分政策成本。

强事件触发条件：

- 某一派连续多年超过 55%-60% 影响力。
- 国家处于危机，例如天命下降、财政低、叛乱高、战争失败、无继承人。
- king 能力太低，被强势官场牵着走。
- 监察长期失效，朋党坐大。

强事件例子：

- 法家变法：加速律令和集权，但贵族不满。
- 儒家尊王修礼：稳定继承和天命，但压低激进改革。
- 墨家守城：边境城墙、箭塔、防守效率提升，但主动扩张下降。
- 兵家请战：战争倾向上升，军队恢复快，但民生压力上升。
- 纵横合纵连横：更频繁拉附庸、联盟、议和。
- 道家休养：降低战意和税负，民怨下降，研发和扩张放缓。
- 农家劝农：粮食、人口恢复、城市发展度提升。
- 阴阳灾异：天命低时触发解释、祭祀、改元类决策。
- 名家辩法：降低宣称和法理类成本，但可能拖慢政策执行。

## UI 窗口

官场窗口优先复用原版可滚动窗口模式，不做复杂自由缩放画布。

窗口结构：

- 顶部：国家名、政体、官场等级、官场效率、主流学派。
- 左侧：学派饼图或色块占比。
- 中部：中央官职列表，显示职位、人物、学派、能力、影响力。
- 下部：地方官署概览，按城市折叠显示地方官和地方学风。
- 右侧或底部：当前官场影响，列出正在推动的科技、国策、决策、政体方向。
- 操作区：任命、罢免、调任、扶持学派。

饼图如果实现风险高，第一版可以用横向堆叠条或小色块比例替代。关键是信息清楚，且 UI 不触发大规模计算。

## 历史记录

不把所有普通任官都塞进国家史，避免刷屏。

国家史记录：

- 首次建立官场。
- 原始朝会升级为百家官场。
- 某学派长期主导国家路线。
- 大规模变法、清议、党争、清洗、废政体、改政体。
- 名臣出任丞相、司马、御史等核心职位。
- 官场导致的重大国策或政体变化。

人物传记记录：

- 入朝为官。
- 出任核心职位。
- 成为某派领袖。
- 被罢免、流放、处死、叛逃。
- 主持变法、劝农、修礼、守城、合纵等重要事件。

城市史记录：

- 任命太守或地方主官。
- 地方官署建立。
- 地方官导致城市发展、治安、民怨、税收明显变化。
- 城市学风形成，例如“临淄多法家士人”。

天命史记录：

- 官场推动称天命、改制、尊王修礼、灾异解释、伪朝 Xia 化。
- 天命王朝内的重大党争和变法。

## 数据结构

新增轻量数据结构：

- `KingdomCourtState`：国家官场总状态、等级、主流学派、效率、刷新年份。
- `CourtOfficer`：官员 actor_id、职位、层级、城市 id、学派、影响力、任命年份。
- `CourtFactionCache`：各学派人数、影响力、占比。
- `CourtCandidateCache`：候选人 actor_id 和评分，低频刷新。
- `CityBureauState`：地方官署效率、地方学风、地方官数量。
- `CourtEventCooldown`：强事件冷却，防止刷屏和频繁改制。

字段需要支持：

- actor 死亡。
- actor 叛逃或改国。
- 城市灭亡。
- 国家灭亡。
- Xia 化状态变化。
- 脏存档缺字段。

脏数据不能崩溃，下一次低频刷新修复。

## 接入现有系统

科技和国策：

- 新增官场制度科技。
- `KingdomPolicyAI` 读取官场缓存调整权重。
- 政体变化仍走现有国策/决策系统，不绕开国家决策。

城市经济：

- 司徒、农家、墨家影响税收、发展度、粮食。
- 城市经济事件写城市史，不污染国家史。

战争和附庸：

- 司马、兵家影响战争目标选择、撤退、占领速度、边军。
- 纵横家影响附庸、联盟、宣称、议和。

天命：

- 儒家、阴阳家影响天命稳定和正统叙事。
- 法家、兵家影响天命王朝扩张和律令帝国路线。
- 外族伪朝 Xia 化后可接入官场，但保留种族贴图和语言文化记录。

## 性能硬约束

官场系统必须遵守以下约束：

- 不做全世界实时扫描。
- 不在每帧计算派系。
- 不在每年对每个城市做大规模排序。
- UI 打开只读缓存。
- AI 只读 `CourtState` 和 `CourtFactionCache`。
- 候选池按国家缓存 top-N，不全王国全量排序。
- 派系比例只在任官变化、死亡、叛逃、每 N 年低频刷新时重算。
- 地方官每城最多 1-3 人，小城只保留 1 人。
- 生成游士必须有国家级冷却。
- 学派 trait 只在任官 actor 身上存在，离官及时清理。

## Benchmark

第一版必须增加分项 benchmark：

- `court_year_tick`
- `court_candidate_refresh`
- `court_officer_validate`
- `court_faction_recalc`
- `court_ai_policy_bias`
- `court_ui_build`
- `city_bureau_refresh`

测试目标：

- 50 年、100 年、200 年后，年更不出现明显新尖峰。
- 国家多、城市多时，地方官署不全量重排。
- 打开官场 UI 不触发大扫描。
- actor 死亡后官职清理不全世界查找。
- 学派 trait 只在任官 actor 身上出现。

- 官场制度科技。
- 中央 6 官职。
- 每城 1-3 地方官。
- 军府汇总现有军事职位。
- 监察低频检查。
- 百家派系缓存。
- AI 软影响。

- 历史记录。
- benchmark。

第一版暂缓：

## 验收标准

- 未解锁官场科技时，王国 UI 显示原始朝会入口。
- 解锁官场制度后，入口变为百家官场。
- 官场窗口能显示中央官、地方官、派系组成和当前路线影响。
- 任官 actor 才拥有学派 trait，离官后清理。
- AI 国家会根据官场缓存调整研发、国策、决策和战争倾向。
- 强事件不会频繁刷屏，且有冷却。
- 国家史、人物传记、城市史、天命史按重要性写入，不污染普通历史列表。
- benchmark 能分辨官场候选刷新、派系重算、UI 构建和年更 tick 的耗时。
- 200 年模拟后官场系统不成为 updateAge/updateYear 主要卡顿来源。
