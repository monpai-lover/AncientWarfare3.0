# Military Prefecture And Court Template Application

## Goal

让军府城市自动成为节度使建立地候选，并允许地方官府、中央朝廷切换预设或自定义模板时，优先迁移现有正式官员，保持任官历史和资格约束。

## Scope

1. 军府城市进入运行时候选索引；候选只包含当前国家、存活城市、当前地方模板为军府的城市。
2. 节度使创建仍复用 `MilitaryGovernorateCreationService` 和现有国策/政策执行链。国策选择城市时读取候选索引，创建成功后刷新索引。
3. 地方官署模板选择同时提供民州、军府以及本国自定义地方 JSON 模板。应用模板通过统一迁移事务处理官员：先快照正式任官，按相同办公室 ID 优先，其次按办公室映射和资格选择；无法匹配的官员进入候选池，不删除历史。
4. 中央朝廷模板应用使用同一迁移事务，优先按办公室 ID、映射和资格填充正式空缺；代理任官不被升级为正式任官。

## Data And Boundaries

- 军府候选是运行时派生数据，不新增持久化城市字段；状态变化由地方模板切换、城市易主、城市销毁和节度使创建事件定向失效。
- 模板应用只提交成功的任官事务；失败时恢复原模板和原任官快照，避免半应用状态。
- 任官迁移不改变官员贵族身份规则，不撤销历史，不绕过现有资格、皇家禁卫和代理任官约束。
- 节度使建立国策仅增加候选城市来源和前置检查，不改变已有战争、继承和军镇运行机制。

## UI

- 地方官署已有模板切换控件扩展为内置民州/军府 + 已导入/保存地方模板列表。
- 节度使国策窗口的建立地选择只显示军府候选城市，并提示当前无候选时无法执行。
- 中央朝廷应用自定义模板沿用现有应用按钮，成功提示迁移结果数量，失败提示回滚原因。

## Failure Handling

- 无军府候选、城市无效、模板不存在、目标办公室冲突或资格不满足时，创建/应用返回失败，不改变现有状态。
- 单个官员无法迁移不阻塞整个模板应用；该官员进入现有候选池并记录原因。
- 所有新增错误记录使用 `LogError`，不使用 `LogWarning`。

## Verification

- 纯规则测试覆盖军府候选、候选失效、模板来源排序、办公室匹配优先级、代理任官排除、事务回滚。
- SourceGuard 覆盖不扫描全世界、复用现有节度使创建服务、地方/中央模板迁移边界。
- Release 构建、源部署哈希和 WorldBox 启动验证。
