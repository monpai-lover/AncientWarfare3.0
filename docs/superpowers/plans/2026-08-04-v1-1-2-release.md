# Ancient Warfare 3 v1.1.2 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, tag, upload, and publish a clean NML source-mod package for Ancient Warfare 3 v1.1.2.

**Architecture:** Update the committed version metadata, validate the current `master`, and construct the ZIP from an explicit runtime whitelist in a temporary directory. Audit the archive with .NET ZIP APIs before removing the obsolete local package, then push the version commit and annotated tag and create a GitHub Release with verified notes and asset metadata.

**Tech Stack:** PowerShell, Git, GitHub CLI, .NET 9 rules tests, net48 MSBuild, `System.IO.Compression.ZipFile`.
