# AW3 任务2：天命战争、外族夺命与天命标修复计划

> 范围说明：本文件只记录“任务2：天命制度完善”。“任务1：性能优化/AW3 Benchmark/禁卫军热点”另起任务处理，不混在本计划内。

## 背景

当前 AW3 已有第一版天命系统：持久化 `MandateState/MandatePeriod/MandateCoreCity/MandateEvent`、天命值、天命榜单、天命地图模式、天命法理、天命战争类型、义军天命战争和外族伪朝入口。

本轮测试暴露出几个制度层问题：

1. 天命标在王国地图模式点击某个国家后会乱跑。现实现把图标挂到 `NameplateText` 的 special icon 字段上，缩放/移动时锚点不稳定。
2. 非 Xia 种族称天命不能通过普通决议完成，必须通过“夺取天命”宣战理由打赢天命战争。
3. 对天命国宣战时，“夺取天命”应作为默认宣战理由，而不是普通征服/核心/宣称优先。
4. 核心/宣称战争目标如果目标土地已经被己方掌控，应进入议和/结算，不应继续空耗战争。
5. 天命战争需要按 AW2 逻辑补强：挑战天命国、判定胜负、转移天命、记录世界日志和历史事件。
6. 天命国如果不是“最强国家”，天命值应快速下跌。最强国家公式要参考 AW2：本国国力 + 附庸国力 * 0.6，并排除附庸国自身竞争。


## 已核实的 AW2 参照

AW2 天命标：

- `MoHCorePatch.SetTianmingicon_Postfix(MapText.showTextKingdom)` 直接替换铭牌 `base_icon.sprite = SpriteTextureLoader.getSprite("moh_nameplate")`。
- 它没有创建额外浮动图标，所以不会出现相机缩放后图标跑到别的国家铭牌旁边的问题。

AW2 天命国力：

- `MoHTools.CalculateKingdomValue(AW_Kingdom k)`：
  - 基础国力来自当前社会等级/政策状态的 `calc_kingdom_strength`。
  - 如果是宗主国，附庸国国力按 `0.6` 折算加入。
  - 附庸国本身不参与“最强国家”候选。

AW2 天命值年度变化：

- 无敌国：`+1`
- 有敌国：`-1`
- 不是最强国家：`-2`
- 正面纪元：`+2`
- 负面纪元：大幅扣分，AW2 为 `-20`
- 天命君主有 `first`：`+5`
- 年幼、低智等负面条件扣分。
- 王族过少扣分。

AW2 天命战争：

- 对天命国发动普通战争时会转成 `tianming`。
- 双方首都归属判定胜负；挑战者胜利时清除旧天命并设置新天命。
- 天命战争有专门 world log。

## 当前 AW3 差异

1. AW3 `MandateMapMarkerService` 使用 `_icon_special/_show_icon_special`，这是天命标乱跑的高风险根因。
2. AW3 `WarDecisionService.HasIntrinsicCasusBelli()` 已允许 `tianming` 对当前天命国生效，但 UI/AI 默认选择和非 Xia 限制还不够明确。
3. AW3 `MandateService.IsMostPowerfulIndependent()` 当前用 `VassalService.GetPowerScore(pIncludeVassals: true)` 和 `1.08` 容差，但没有明确复刻 AW2 的“附庸 0.6 权重”公式。
4. AW3 `OnWarEnded()` 已能在天命战争攻击方胜利时转移天命，但战争目标、默认理由、已控制目标议和、历史记录还需要收口。

## 目标设计

### 1. 天命标修复

改为 AW2 的稳定做法：

- Patch 仍挂 `NameplateText.showTextKingdom`。
- 不再使用 `_icon_special`。
- 反射并替换原版铭牌主图标字段，优先目标：
  - `base_icon`，如果新版类没有该字段，则查找等价的 species/base icon 字段。
  - 已有 `NameplateText` 字段时只替换 sprite，不创建新对象。
- 当前天命国使用 `moh_nameplate`。
- 义军/伪朝如要显示，必须使用同一个稳定主图标替换路径；如果会影响普通王国铭牌，则先只保证真天命国。
- 切换地图模式、缩放、点击王国后不得出现第二个游离天命标。

验证：

- 王国地图模式点击天命国。
- 缩放/移动视角。
- 天命标必须贴在该国铭牌主图标位置，不跟随其他国家铭牌漂移。

### 2. 非 Xia 入关夺命规则

非 Xia 种族不能通过普通“称天命/受命称帝”决议直接拿天命。

允许路径：

- 非 Xia 国家满足外族入关条件后，获得对当前天命国的 `夺取天命` 宣战理由。
- 打赢 `tianming` 战争后，才可进入 `pseudo_foreign / foreign_pseudo` 天命状态。
- 胜利后执行 Xia 化政治接入：
  - `XiaizationService.OnPseudoMandateDeclared()`
  - 伪朝标记
  - 历史记录写明“外族入关，夺取天命，建立伪朝/新朝”。

禁止路径：

- 非 Xia 国家不能通过 `aw_decision_claim_mandate` 直接 `TryDeclareMandate()`。
- AI 也不能绕过战争直接称天命。

### 3. “夺取天命”宣战理由

对当前天命国宣战时：

- 如果攻击方不是当前天命国，且目标是当前天命国，优先显示并默认选择 `夺取天命`。
- `夺取天命` 高于：
  - 收复核心
  - 强宣称
  - 弱宣称
  - 征服
  - 无理由宣战
- 如果攻击方是天命国附庸，则按附庸规则：
  - 可用独立战争或天命体系内部特殊叛乱。
  - 普通附庸不能随便夺取天命。

UI：

- 战争目标窗口第一行默认高亮 `夺取天命`。
- tooltip 显示：
  - 宣战理由：夺取天命
  - 目标：当前天命国
  - 胜利效果：转移天命/建立伪朝/义军受命
  - 失败效果：天命国恢复天命值，攻击方承受失败历史记录。

AI：

- 当目标是天命国时，AI 优先评估 `夺取天命`。
- 如果攻击方国力远弱于天命国，不轻易发动。
- 如果天命国天命值低、法理控制低、战争中、继承危机，AI 倾向提高。

### 4. 核心/宣称战争的已控制目标结算

需要补一个战争目标结算规则：

- `收复核心`：目标核心城市已经在攻击方或其直属体系控制下，则允许结算。
- `强宣称/弱宣称`：目标宣称城市已经在攻击方或其直属体系控制下，则允许结算。
- 如果所有目标城市已经满足控制，自动进入议和/战争结束流程。
- 不能让“目标已经拿下”但战争继续耗着。

注意：

- 这个规则不替代天命战争。
- 天命战争结算仍按天命战争目标：首都/法理核心/战争胜负综合判定。

### 5. 天命战争结算按 AW2 补强

AW3 不应只看普通战争 winner，需要有天命战争专用目标状态。

推荐规则：

- 记录开战时：
  - 攻击方首都
  - 天命国首都
  - 天命国核心法理城市集合快照
  - 邻接/目标城市候选
- 战争中如果攻击方控制天命国首都，或控制足够高比例天命法理核心，判定攻击方达成目标。
- 天命国如果夺回首都并长期稳定，或攻击方崩溃/议和失败，判定防守胜利。
- 攻击方胜利：
  - `ClearMandate("war_lost")`
  - Xia 正统挑战者：`TryDeclareMandate(attacker, "tianming_war")`
  - 义军：`TryDeclareMandate(attacker, "tianmingrebel_war", "rebel", "rebel", defender)`
  - 外族：`TryDeclareMandate(attacker, "pseudo_foreign_war", "pseudo_foreign", "foreign_pseudo", defender)`
- 防守方胜利：
  - 天命值增加。
  - 记录“平定天命挑战”。

### 6. 最强国家公式重做

新增一个明确规则类：

- `MandatePowerRules`

计算：

```text
天命竞争国力 = 本国基础国力 + 直属/间接附庸国力 * 0.6
```

候选过滤：

- 排除 neutral / rekt / 非 civ。
- 排除附庸国本身。
- 排除不支持天命体系的国家，除非正在走“外族入关夺命”路径。

基础国力建议：

- 优先复用现有 `VassalService.GetPowerScore(k, false)` 或王国现有 power。
- 如果 AW3 政体/国策有国力计算函数，后续可接入，但本轮先要稳定复刻 AW2 口径。

天命值影响：

- 天命国不是最强国家：基础每年 `-2`。
- 如果最强国家国力超过天命国 `1.25x`：额外 `-2`。
- 如果超过 `1.75x`：额外 `-4`，并提高 AI 夺取天命倾向。
- 如果超过 `2.5x`：进入严重危机提示。

### 7. 年度天命变化收口

沿用 AW2 但适配 AW3：

- 和平：`+1`
- 有敌国：`-1` 到 `-2`
- 不是最强：按上面公式扣分
- 法理控制：
  - 高控制加分
  - 低于 50% 大扣分
- 附庸忠诚：
  - 高忠诚小加分
  - 低忠诚扣分
- 纪元：
  - 希望/奇迹：`+2`
  - 绝望/灰烬/混沌：`-12` 到 `-20`，最终数值测试后定
- 君主：
  - `first/figure`：`+5`
  - 年轻、低智低外交扣分
  - 高外交/高管理小加分
- 子嗣：
  - 即位 10 年后仍无合法子嗣才扣天命。
  - 不因刚即位没孩子立刻崩。

### 8. 历史记录和本地化

新增/补齐事件：

- `mandate_war_claim_created`：获得夺取天命理由
- `mandate_war_start`：发动夺取天命战争
- `mandate_war_goal_reached`：达成天命战争目标
- `mandate_war_won`：天命战争胜利
- `mandate_war_defended`：天命国守住天命
- `mandate_foreign_pseudo_started`：外族入关建立伪朝
- `mandate_power_decline`：非最强国导致天命流失

所有文本需要 zh/en/ch 本地化，不直接写乱码常量。

历史记录：

- 国家历史：记天命战争开始、胜败、天命转移、伪朝建立。
- 天命榜单：记入对应朝代/君主段。
- 人物传记：攻击方 king、天命皇帝、义军领袖/外族入关君主都要记录。

### 9. 与任务1性能优化的边界

本计划不实现 AW3 benchmark 面板和禁卫军优化，但天命实现必须避免新增性能问题：

- 年度天命计算只按年触发，不逐帧触发。
- 最强国家计算缓存到年度 tick，避免每帧遍历。
- 天命地图模式复用缓存，不在每个 tile/zone 上重复扫所有国家/附庸。
- 天命标只替换铭牌 sprite，不创建额外对象。

## 验收标准

- 天命标在王国地图模式缩放/移动/点击国家后不乱跑。
- 非 Xia 国家不能点普通称天命决议直接称帝。
- 非 Xia 国家可通过对天命国发动“夺取天命”战争并胜利建立伪朝。
- 对天命国打开战争目标时，默认第一项是“夺取天命”。
- 核心/宣称目标已被己方控制时，战争会进入结算，不继续空转。
- 天命国不是按 AW2 口径计算的最强国家时，天命值明显下跌。
- 天命战争胜败、伪朝建立、天命转移都进入国家历史、人物传记和天命榜单。

## 追加需求：外族伪朝与天命法理收口

本节补充 2026-07-07 测试反馈，属于本计划的天命体系完善范围。

### 10. 天命史记录口径

当前问题：无论天命来源是什么，历史记录都显示成“正统受命”，这会把正常受命、义军受命、外族夺命和伪朝混成一类。

修复口径：

- Xia 正统国家通过正常判定称帝：记录为“受命称帝”或“正统受命”。
- Xia 义军通过天命战争或义军统一路径称帝：记录为“义军受命”。
- 非 Xia 国家通过夺取天命战争胜利称帝：记录为“外族入关，夺取天命，建立伪朝”。
- 历史人物建立天命国仍必须走天命判定流程；历史人物可免除爵位/礼制要求，但不能跳过强弱、法理和战争路径记录。
- 天命榜、国家史、人物传记都必须带 `mandate_origin` / `mandate_claim_type` 快照，避免 UI 只按当前状态反推。

新增/补齐事件建议：

- `mandate_declared_orthodox`
- `mandate_declared_rebel`
- `mandate_declared_foreign_pseudo`
- `mandate_usurped_by_war`
- `mandate_foreign_xiaized`

### 11. 外族伪朝 Xia 化接入

外族皇帝不能被改成 Xia 种族；种族、语言、文化保留原本体系。但外族伪朝成为天命王朝后，政治、氏族、官员、历史记录必须接入 AW3 Xia 模组体系。

规则：

- 非 Xia 国家夺取天命后，国家状态进入 `foreign_pseudo` / `pseudo_foreign`。
- 王国体制接入 AW3：国策系统、天命史、国家史、城市史、人物传记、氏族树、官员身份都可用。
- 氏族系统 Xia 化：外族皇帝和重要官员建立 AW3 `LINEAGE_ID / SHI_ID / CLAN_NAME`，但不改 species。
- 官员接入：外族伪朝的 king、city leader、army leader、general 都应能进入 AW3 官职/传记/氏族显示体系。
- 子嗣继承：外族伪朝王族子嗣也继承 AW3 氏族字段，避免只在王本人身上有记录。
- 语言和文化保留：不把 human/orc/其他种族的语言文化直接改成 Xia，只做政治和氏族制度 Xia 化。

命名规则：

- 外族国名改国号时取可显示王国名的第一个有效字符作为国号，例如“苏莱曼 加尔·诺恩”类名称按符号和空白切分，取第一个姓名/国名片段的首字符。
- 需要兼容中文名 human 的命名规则：优先使用明确分隔符切分，分隔符包括空格、点号、间隔号、连字符和原版名称分隔符。
- 伪朝国名记录必须保存 `original_kingdom_name`，UI 展示当前国号时仍能 tooltip 看到原名。

### 12. 天命附庸地图颜色

当前问题：天命王朝敌国/附属国地图中，天命附属国使用自己的国家颜色，导致看不出天命体系范围。

修复口径：

- 天命王朝地图模式以天命国颜色为体系色。
- 当前天命国使用天命国颜色。
- 当前天命国的直属/间接附庸也使用天命国颜色或同色高亮变体，而不是附庸自己的颜色。
- tooltip 中仍显示附庸本国颜色、宗主、根宗主和天命体系关系。
- 规则对齐附庸地图：附庸体系区域表达宗主体系，不表达附庸自身独立颜色。

### 13. 天命法理永久保留

当前设计必须明确：旧天命国家的天命法理不会因为王朝灭亡而消失。

规则：

- 如果 A 朝拥有 B 地并将其纳入天命法理，A 朝灭亡后，B 地仍作为历史天命法理保留在 `MandateCoreCity`。
- 新天命王朝可在已有法理基础上扩展自己的天命法理，但不能清空旧朝记录。
- 天命法理地图需要区分：
  - 当前天命国控制的法理
  - 当前天命附庸控制的法理
  - 当前天命体系失去的法理
  - 历史旧朝保留法理
- 天命建立、复国、夺命战争判断可以读取历史法理，但要标明这是“旧朝法理”还是“当前王朝法理”。
- 年度法理扩张只新增或更新活跃记录，不删除旧王朝法理档案。

验收补充：

- 外族夺取天命后，天命榜不能显示为普通“正统受命”，必须显示伪朝来源。
- 外族皇帝仍是原 species，但能显示 AW3 氏族、官职、人物传记和天命史。
- 伪朝国号取名稳定，不出现完整外文长名直接作为朝名。
- 天命王朝地图中，天命附庸区域随天命国颜色显示。
- A 朝灭亡后，A 朝曾经纳入的天命法理仍可在历史/法理系统中查询。
