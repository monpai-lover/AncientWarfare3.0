# AW3 大将、受赏封地、拥兵自重叛乱计划

## AW2 参考结论

AW2 没有完整成品的大将封地系统，现存内容主要是这些碎片：

- 附庸关系：手动设附庸、解除附庸、主动附庸、附庸战争、吞并附庸、独立战争。
- 叛乱基础：原版 rebellion 改写、天命叛乱、城市独立、支持者加入战争。
- 军功基础：士兵/军队在原版战争胜负中获得 renown，AW2 设想过“军功授爵”但没有完整封地闭环。
- 地图模式：附庸 mapmode 按根宗主国颜色显示整个附庸体系。

AW3 本次已经补上附庸系统基础和附庸 mapmode。大将/封地/拥兵叛乱应作为下一个独立系统实现，不直接照抄 AW2 半成品。

## 目标

建立一套“军功 -> 大将 -> 受赏封地 -> 拥兵自重 -> 叛乱/自立/附庸”的闭环：

- 大将不是单纯 trait，而是国家军事权力节点。
- 封地不是纯文本记录，而要绑定城市、军队、个人功勋和忠诚。
- 拥兵自重不是随机叛乱，而是由个人军事实力、封地资源、君主能力、宗族关系和奖惩共同驱动。
- 所有关键事件进入人物传记、国家历史、城市编年史。

## 数据设计

新增 `GeneralState` 表：

- `actor_id` 主键。
- `actor_name`、`kingdom_id`、`kingdom_name`、`kingdom_color`。
- `home_city_id`、`home_city_name`。
- `fief_city_id`、`fief_city_name`。
- `personal_army_id`。
- `merit_score` 军功。
- `loyalty_score` 忠诚。
- `ambition_score` 野心。
- `troop_power_snapshot` 个人掌兵估值。
- `granted_time`、`last_reward_time`、`last_rebellion_check_time`。
- `active`、`rebelled`、`end_reason`。

新增 `FiefGrant` 表：

- `grant_id` 主键。
- `general_actor_id`。
- `kingdom_id`、`king_id`。
- `city_id`、`city_name`、`city_color`。
- `grant_reason`：军功、王室、安抚、边防、复国、附庸整合。
- `start_time`、`end_time`。
- `revoked`、`revoke_reason`。

## 大将判定

候选来源：

- 原版 army captain。
- 城市 leader 兼长期带兵者。
- 贵族军功高者。
- 王室非继承人且成年男性。

成为大将条件：

- 成年、非奴隶、非继承人。
- 至少参与过战争或所在军队有 renown。
- `warfare`、`stewardship`、`diplomacy` 综合达到本国军人前 20%。
- 若国家完成“军功授爵”，平民优秀将领也可进入大将候选。

大将上限：

- 小国最多 1 名。
- 3 城以上最多 2 名。
- 6 城以上最多 3 名。
- 超过上限时按军功和当前军队重要性保留。

## 军功

军功来源：

- 作为 army captain 赢得战争。
- 攻破城市。
- 防守本城成功。
- 参与附庸战争、独立战争、复国战争。
- 保护国王或击杀重要人物。

军功用途：

- 触发受赏。
- 触发大将称号。
- 提高个人传记重要性。
- 抵消低出身惩罚。
- 同时提高野心，长期不受赏会降低忠诚。

## 受赏封地

封地对象：

- 边境城市。
- 新征服城市。
- 人口较少但战略位置重要的城市。
- 大将原驻军城市。

禁止封地对象：

- 首都。
- 继承人所在核心城市。
- 正在叛乱或刚被攻破未稳定的城市。
- 已经是其他大将封地的城市。

授封效果：

- 记录 `FiefGrant`。
- 城市 tooltip 显示“某某封地”。
- 大将个人传记记录受封。
- 城市编年史记录受封。
- 国家历史记录“封某某于某城”。
- 大将忠诚上升，野心也小幅上升。

## 拥兵自重

每年检查大将风险：

- 个人军队人数 / 全国军队人数。
- 封地人口 / 全国人口。
- 封地城市数。
- 大将军功。
- 大将是否王室、同氏、外戚、异氏。
- 大将与君主亲缘距离。
- 君主能力、年龄、是否幼主。
- 国家是否战败、内乱、附庸压迫、国策变动。
- 是否长期未受赏。

忠诚加分：

- 同父系王族。
- 曾受赏且近期未被削权。
- 君主高 diplomacy / stewardship。
- 国家强盛且战争胜利。
- 大将封地安全。

叛乱加分：

- 个人掌兵超过全国 35%。
- 封地人口超过全国 25%。
- 君主幼弱或频繁战败。
- 大将军功高但多年未受赏。
- 异氏大将掌边境重兵。
- 宗主国弱、附庸体系不稳。

## 叛乱类型

拥兵自重不只一种结果：

- 逼宫：大将在首都附近且影响力超过国王，尝试夺王位。
- 割据：封地城市独立成新国。
- 投附：大将带封地向强邻称臣，成为附庸。
- 复国：若大将有亡国王室 claim，带封地复国。
- 兵变：只更换 city leader 或 army captain，不立即建国。

## 战争接入

新增战争类型：

- `general_rebellion_war`：大将叛乱。
- `fief_independence_war`：封地独立。
- `restoration_war`：复国战争，复用现有 `RoyalClaimService`。

战争参与规则：

- 大将封地城市加入叛军。
- 与大将同氏支、同封地、同军队者优先支持。
- 忠于王室的禁卫军默认站国王。
- 附庸国可按关系支持宗主或叛将。
- 强邻可支持复国战争，胜后决定附庸或友好。

## 历史记录

人物传记：

- 被任为大将。
- 建立军功。
- 受赏封地。
- 被削封。
- 拥兵自重。
- 发动叛乱、复国、投附。
- 战败被诛、被赦免、流亡。

国家历史：

- 任命大将。
- 封某某于某城。
- 某封地叛乱。
- 某大将复国/投附/被平定。

城市编年史：

- 成为某大将封地。
- 封地被收回。
- 城市随大将叛乱。
- 城市在叛乱后归属变化。

## UI

人物传记：

- 左侧 tab 增加“大将/封地”状态块。
- 显示军功、忠诚、野心、封地、掌兵比例。

国家历史：

- 王朝/君主时期折叠项下显示大将任免和封地事件。

城市编年史：

- 在君主时期分段里显示封地归属。

地图模式：

- 后续可增加“封地地图”。
- 颜色按封地持有人或直属王权显示。
- tooltip 显示封地持有人、军功、忠诚、叛乱风险。

## 实施顺序

1. 建表：`GeneralState`、`FiefGrant`。
2. 写 `GeneralService`：候选、任命、军功、忠诚、风险计算。
3. 接战争结果：给 army captain、守城者、攻城者累计军功。
4. 实现受赏封地：选择城市、写表、写历史、更新 tooltip。
5. 实现年度风险检查：只记录高风险，不立刻叛乱。
6. 实现封地叛乱：城市独立、战争、支持者。
7. 接入附庸：叛将可向强国称臣，强国可支持复国。
8. UI 展示：人物传记、城市编年史、国家历史、后续封地 mapmode。

## 风险控制

- 不直接每年全量遍历所有 actor，只遍历 king/city leader/army captain/已有 GeneralState。
- 大将上限与封地上限必须严格限制，避免后期历史表爆炸。
- 叛乱检查必须有冷却，默认 10 年。
- 继承人、国王本人、奴隶、禁卫军成员默认不能成为割据大将。
- 先做记录和封地，再做实际叛乱，避免一次性改动过大。
